# RecallRocket — Master Any Academic Subject

A responsive flashcard learning application built with **HTML, CSS and vanilla JavaScript**.

## Run the project
1. Download and extract `RecallRocket.zip`.
2. Open the `RecallRocket` folder.
3. Double-click `index.html` (or open it with VS Code Live Server).
4. No installation, build process, server, or API key is required.

## Features
- Dashboard with flashcard, mastery and study-streak statistics
- Add custom subjects and subject-wise flashcards
- Create, edit and delete flashcards
- Search and filter by subject and learning status
- Interactive 3D flip-card study session
- Shuffle, previous/next, Known and Need Revision controls
- Progress dashboard with subject-level mastery bars
- Light/dark appearance toggle
- Responsive desktop, tablet and mobile layout
- Saves subjects, cards, statuses and study dates in browser LocalStorage
- Includes sample cards so the application is ready to demonstrate

## Project structure
- `index.html` — semantic page structure and application views
- `style.css` — responsive design, theme variables, animations and components
- `script.js` — application logic, flashcard interactions and LocalStorage persistence

## Notes
This is a front-end academic mini-project. Data is stored in the current browser using LocalStorage, so it does not automatically sync between devices or browsers. The spaced-repetition concept is demonstrated through revision status and progress tracking; an adaptive scheduling algorithm and backend account system can be added as future enhancements.
